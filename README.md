# Baseline

A private iPhone app that turns Apple Health data (from an Amazfit Helio Strap and the phone) into a daily recovery score, calorie balance and training picture. Built with Expo and Claude Code, installed for free with a personal Apple ID.

- **Design:** [docs/DESIGN.md](docs/DESIGN.md)
- **Set up and install (Windows):** [docs/SETUP.md](docs/SETUP.md)
- **Working on it with Claude Code:** [CLAUDE.md](CLAUDE.md)

```
npm install
npm test        # metric maths
npm run web     # browser preview with sample data
```

Not medical advice. Scores compare you with your own recent history.
